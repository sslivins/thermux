Sensor channels

Each sensor keeps its channel, so register addresses don't change when sensors are added or the bus is rescanned. Channel N's temperature is in input register 100+N, in hundredths of a degree. Moving a sensor onto a used channel swaps the two. A channel can only be released once its sensor is disconnected.
